편집 모드 연결 (처음 한 번만)

홈페이지에서 바로 작업물을 올리려면, 이 사이트가 내 GitHub 저장소를 수정할 수 있는 열쇠(토큰)가 필요해요. 토큰은 지금 쓰는 이 브라우저에만 저장되고 다른 사람에게는 보이지 않아요.

  1. GitHub 토큰 만들기 페이지 ↗를 열어요.
  2. Token name: 아무 이름(예: portfolio-edit), Expiration: 90일 또는 1년 추천 (만료돼도 올린 파일은 그대로예요)
  3. Repository access → Only select repositories → canyo791/portfolio
  4. Permissions에서 + Add permissions → Contents를 체크하고, 오른쪽 Access를 Read and write로 바꿔요.
  5. 맨 아래 Generate token을 누르고 나온 값(github_pat_…)을 복사해 아래에 붙여 넣어요.
공용 PC에서는 다 쓴 뒤 편집 바의 [연결 해제]를 눌러 주세요.
