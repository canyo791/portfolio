# Yoon Hyemin · 2D Animator Portfolio

홈페이지: https://canyo791.github.io/portfolio/

## 홈페이지에서 바로 편집하기 (추천)

1. 홈페이지 맨 아래 © 줄 옆 **관리**를 눌러요.
2. 처음 한 번만 GitHub 토큰을 만들어 붙여 넣어요. 창에 순서가 나와요. 토큰은 그 브라우저에만 저장돼요.
3. 편집 모드에서
   - 칸에 파일을 **끌어다 놓거나 [올리기]** → 교체
   - 카드 아래 **✎ 칸**에서 이름 수정
   - **＋ 작업물 추가**로 새 칸 만들기, **✕**로 칸 지우기
   - **여러 파일 한 번에 올리기**: 파일 이름이 같은 칸에 자동으로 들어가요
   - 메인 영상 아래 **유튜브** 칸에 주소를 넣으면 페이지 안에서 재생돼요
4. 다 끝나면 **[저장하기]** → 1~2분 뒤 모두에게 보여요.

지원 형식: gif · png · jpg · webp · mp4 · webm (파일 하나 95MB 이하, 사이트 전체 1GB 이하)

## 파일 구조

- `content.json` — 홈페이지 글과 작업물 목록 (편집 모드에서 자동으로 고쳐져요)
- `media/<프로젝트>/` — 작업물 파일
