# Yoon Hyemin · 2D Animator Portfolio

홈페이지 주소: https://canyo791.github.io/portfolio/

## 작업물 파일 올리기 (GitHub 웹사이트에서)

1. 이 저장소에서 `media` 폴더 → 프로젝트 폴더(`hallow-stone`, `devi-rush`, `project-vs`, `animation`)로 들어가요.
2. 오른쪽 위 **Add file → Upload files**를 눌러 파일을 끌어다 놓아요. 여러 개를 한 번에 올려도 돼요.
3. 아래 **Commit changes**를 누르면 1~2분 뒤 홈페이지에 반영돼요.

- 각 폴더의 `README.md`에 **어떤 파일 이름이 어느 칸에 들어가는지** 표로 정리돼 있어요. 이름이 같아야 제자리에 들어가요.
- 같은 이름으로 다시 올리면 교체돼요.
- 지원 형식: gif · png · jpg · webp · mp4 · webm (파일 하나 100MB 이하, 사이트 전체 1GB 이하)
- GIF는 MP4로 바꾸면 용량이 크게 줄어요. 홈페이지에서 MP4도 GIF처럼 자동 반복 재생돼요.

## 이름 바꾸기 · 작업물 추가 · 유튜브 영상

`content.js` 파일을 열고 연필 아이콘(Edit)을 눌러 고친 뒤 **Commit changes**를 누르면 돼요. 파일 맨 위에 방법이 적혀 있어요.

- 긴 영상은 유튜브(일부 공개)에 올리고 `youtube:"영상ID"`만 적으면 홈페이지 안에서 바로 재생돼요.
